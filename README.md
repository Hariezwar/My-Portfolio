## ✨ Features

- **Glassmorphism Design System**: Beautiful translucent overlays with subtle borders (`backdrop-blur`).
- **Dynamic Bento Grids**: Asymmetric, highly organized card layouts inspired by modern Apple & Stripe UI.
- **Interactive 3D Background**: A mesmerizing, real-time reactive 3D liquid waves background powered by Vanta.js and Three.js.
- **Liquid Smooth Scrolling**: High-performance scrolling physics driven by Lenis.
- **3D Card Hover Effects**: Interactive element tilting powered by Vanilla-Tilt.js for a tactile user experience.
- **Flawless Responsiveness**: Meticulously optimized for desktop, tablet, and mobile viewing.
- **Rate-Limit-Proof GitHub Integration**: Repositories are cleanly hardcoded to guarantee zero-latency loading and zero API blockages.

## 🛠️ Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **HTML5 & CSS3** | Core structure and styling |
| **Tailwind CSS** | Utility-first, highly scalable styling framework |
| **Vanilla JavaScript** | DOM manipulation and logic |
| **GSAP & ScrollTrigger** | High-performance reveal animations |
| **Lenis** | Custom smooth-scroll physics engine |
| **Vanta.js (Three.js)** | Real-time WebGL 3D wave backgrounds |
| **Vanilla-Tilt.js** | Interactive 3D tilt effects for Bento cards |
| **Lucide Icons** | Clean, scalable, modern vector icons |
